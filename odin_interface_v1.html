    Plan Engine

    PLAN = source of truth.

    COURSE → LEVEL → MODULE → TOPIC → LESSON → DAY

    Lesson Factory / ССУДТ

    ССУДТ створює базові уроки курсу по темах і порядку, визначеному ДТ Plan Engine.

    • base lessons
    • practice lessons
    • review lessons

    ISSU Support

    ІССУ — не основа курсу, а on-demand support module.

    • photo → support lesson
    • homework explanation

    Platform / Execution

    Платформа показує активний урок з PLAN, веде review/progress/daily/AI, але не вирішує що вчити.
