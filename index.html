Core Flow

→ DT_PLAN_ENGINE creates course plan → Topic is selected from plan → SSUDT generates base/practice/review lessons → ISSU generates support lessons only when needed → QA validates lesson standard → Content Index registers lesson metadata → Platform opens lesson via viewer → Progress updates lesson/topic/course state
