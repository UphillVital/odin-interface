Core Architecture

DT = планує ССУДТ = створює базові уроки ІССУ = підсилює / адаптує on-demand Platform = виконує навчання ODIN = контролює / валідовує / координує

ODIN Loop

detect context → validate against locks → select next action → execute or hold → QA → changelog → snapshot if stable

DT System

PLAN = source of truth PLAN ↔ TOPIC ↔ LESSON ↔ PLATFORM ↔ REVIEW ↔ PROGRESS

Content Pipeline

Pipeline виробництва уроків від плану до платформи.

→ DT_PLAN_ENGINE → TOPIC → SSUDT base/practice/review lessons → optional ISSU support lesson → QA gate → Content Index → Platform → Progress
