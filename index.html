ODIN v68.1 PRO — Stable Integrated Autonomous Loop

→ detect context → validate against locks → select next action → execute or hold → QA → changelog → snapshot if stable

Loop Rules

  • No uncontrolled build
  • No role mixing
  • No architecture change without changelog
  • Stable points require explicit fixation
  • If risk is high, switch to validation mode

DT Plan Engine

PLAN = source of truth.

COURSE → LEVEL → MODULE → TOPIC → LESSON → DAY

ССУДТ

Створює базові уроки курсу по плану: base, practice, review. Не планує курс.

ISSU

On-demand support: фото, домашка, слабка тема. Завжди привʼязується до topic_id.

DT Platform

Виконує навчання: уроки, review, progress, daily plan, AI. Не вирішує що вчити.

Core Link Model

PLAN ↔ TOPIC ↔ LESSON ↔ PLATFORM ↔ REVIEW ↔ PROGRESS active_lesson_id = from PLAN resume_position = UX only progress = lesson + topic + course support_lesson = ISSU + topic_id
