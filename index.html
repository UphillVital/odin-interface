Update Protocol

  1. Визначити, що змінюється.
  2. Якщо змінюється структура — спочатку JSON.
  3. Якщо змінюється інтерфейс — оновити index.html.
  4. Якщо змінюється пояснення — оновити MD.
  5. Кожна суттєва зміна → changelog.
  6. Commit у GitHub з чітким повідомленням.
  7. Перевірити GitHub Pages.
  8. Після stable — створити ZIP backup.

Hard Locks

  • LOCK: Не редагувати HTML без changelog.
  • LOCK: Не змінювати архітектуру тільки в HTML.
  • LOCK: Не завантажувати паролі/API keys/secrets.
  • LOCK: Не покладатися тільки на локальні файли.
  • LOCK: Не перезаписувати stable без backup.
