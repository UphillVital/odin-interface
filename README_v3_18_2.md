# ODIN v3.18.2 STANDALONE LANGUAGE HIGHLIGHT FIX

Проблема v3.18 / v3.18.1:
- У Preview зовнішні кнопки ODIN працювали.
- В окремому HTML уроці / збереженому уроці кнопки Topic / All Rules / OFF були активні, але не перемикали підсвітку.
- Видимою залишалась тільки часткова Topic-підсвітка.

Причина:
- Внутрішній script уроку міг не запускатись або не ловити події після відкриття export/saved HTML.
- Тому перемикання не було повністю автономним.

Fix v3.18.2:
- Кнопки Topic / All Rules / OFF у самому уроці тепер працюють через прямий inline onclick.
- Вони не залежать від зовнішньої оболонки ODIN.
- Вони не залежать від внутрішнього addEventListener.
- Кнопка локального перекладу прикладу також має standalone onclick.

Тест:
1. Розпакувати пакет і замінити dev/.
2. Відкрити через Live Server.
3. Створити урок.
4. Перевірити Preview.
5. Натиснути "Завантажити урок".
6. Відкрити завантажений HTML окремо.
7. У самому HTML уроці натиснути:
   - Topic
   - All Rules
   - OFF
8. Очікувано:
   - Topic: підсвічує тільки відокремлювану частку.
   - All Rules: підсвічує підмет + дієслово + частку.
   - OFF: прибирає підсвітку.
9. Зберегти урок у Saved Lessons.
10. Відкрити збережений урок і повторити тест.

Важливо:
Старі збережені уроки, створені до v3.18.2, можуть не мати нового standalone-коду.
Для чистого тесту потрібно створити і зберегти новий урок після встановлення v3.18.2.
