# ODIN Interface

Online control-center for the ODIN / Deutsch Trainer system.

## Current version

`ODIN_INTERFACE_v2_FULL_INTEGRATION`

## Main file

`index.html`

This is the file served by GitHub Pages.

## Core idea

```text
DT = plans
SSUDT = creates base lessons
ISSU = supports/adapts
Platform = executes learning
ODIN = controls / validates / coordinates
```
