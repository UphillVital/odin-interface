# ODIN V03 — State System

## Призначення

State System потрібна, щоб ODIN бачив не лише файли, а й осмислені стани системи: стабільні точки, checkpoint-и, експерименти та можливість повернення.

## Головне правило

Git залишається джерелом істини, але ODIN отримує власний шар розуміння станів через:

- `dev/V03/STATE_REGISTRY.json` — системний реєстр для інтерфейсу;
- `dev/V03/_states/` — людські описи станів;
- `dev/V03/CHANGELOG.md` — загальна історія розвитку;
- Git commit + tag — технічна фіксація.

## Restore

На цьому етапі ODIN не виконує Git-команди автоматично. Він тільки генерує безпечні команди для користувача.
