# STATE_UI_SPEC.md

## UI-рішення

State System має два рівні відображення:

1. Right Panel Widget — короткий поточний стан.
2. State Workspace — повна робота зі станами.

## Right Panel Widget

Показує:

- current state;
- status;
- останній checkpoint;
- кнопку відкриття State Workspace.

## State Workspace

Має містити:

- Current State;
- History;
- State Details;
- Restore Commands;
- Create State через Commit Builder;
- у майбутньому Compare.
