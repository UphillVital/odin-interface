# STATE_RULES.md

## Основні правила

1. Кожен важливий встановлений пакет після тесту має бути кандидатом у State.
2. Stable State створюється тільки після перевірки користувачем.
3. Restore на першому етапі тільки генерує команди, без автоматичного виконання.
4. Усі описи — українською.
5. State Registry — машинний шар, `_states/` — людський шар.

## Заборонено

- створювати State без Git tag;
- створювати tag без опису;
- змінювати старі State без явної причини;
- виконувати `reset --hard` автоматично з UI.
