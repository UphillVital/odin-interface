# ARCHITECTURE UPDATE — INTERNAL PREVIEWER v1

## Що додано

Додано системний модуль Internal Build Previewer.

## Роль

Previewer дозволяє переглядати результат до затвердження або збереження.

## Межі

Previewer не є редактором, QA або export-системою. Він є контрольним переглядом між редагуванням і затвердженням.

## Сумісність

Не змінює:
- стиль 13.2;
- UA / EN / DE;
- теми;
- Quick Settings;
- contextual help;
- File Workspace workflow.
