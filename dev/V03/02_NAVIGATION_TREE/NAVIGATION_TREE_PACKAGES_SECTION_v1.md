# NAVIGATION TREE — PACKAGES SECTION v1

## Новий розділ дерева

У лівому дереві ODIN V03 має зʼявитися службовий розділ:

```text
System
└─ Packages
   ├─ Package Index
   ├─ PACKAGE 21 — Snapshot System
   ├─ PACKAGE 22 — Internal Previewer
   ├─ PACKAGE 23 — Commit Builder
   └─ ...
```

## Призначення

Розділ `Packages` потрібен для:

- перегляду історії пакетів;
- швидкого доступу до README кожного пакету;
- перегляду changelog-entry;
- перевірки, що було додано або змінено;
- підготовки до майбутнього Package Index у UI.

## Правило

Розділ `Packages` не є робочою зоною редагування коду. Це навігаційний і довідковий шар.

## Майбутнє розширення

Наступний крок:

```text
PACKAGE INDEX — таблиця всіх пакетів прямо в ODIN UI
```
