# NAVIGATION TREE — PROJECTS v1

## Purpose

The left tree must show ODIN as a system with project-level workspaces.

## Tree Model

```text
ODIN
├─ Command Center
├─ System Map
├─ OIS
├─ Projects
│  ├─ Deutsch Trainer (DT)
│  │  ├─ Overview
│  │  ├─ ІССУ
│  │  ├─ ССУДТ
│  │  ├─ Lessons
│  │  ├─ Templates
│  │  ├─ QA
│  │  ├─ Packages
│  │  └─ Documentation
│  │
│  ├─ New Project 1
│  ├─ New Project 2
│  └─ New Project 3
│
├─ File Workspace
├─ Experiments
├─ Manual / Help
└─ System Settings
```

## Rule

The tree must not be decorative. Every tree item must activate a meaningful Work Zone or explain why it is not yet implemented.

## Assisted Mode Requirement

If the user opens a project area and the relationship is unclear, ODIN must explain:

- what this area is
- why it exists
- what can be done here
- what the next recommended action is
