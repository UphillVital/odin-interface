# PACKAGE 16 — Header Quick Settings

## Purpose
Clean the ODIN Interface header without changing the accepted Package 13.2 visual style.

## Changes
- Removed the `ODIN SYSTEM — MASTER START` button from the header.
- Kept MASTER START inside the Command Zone as the primary scenario action.
- Moved Theme and Language controls into a right-corner quick settings menu.
- Added a settings gear button in the header.
- Added language pills: UA / EN / DE.
- Active language has a flag-style visual background. UA is blue/yellow when active.

## QA
- Open `index.html`.
- Confirm header is cleaner.
- Click the gear button.
- Change theme Light/Dark.
- Change UA/EN/DE.
- Reload page and confirm selected language and theme remain saved.
