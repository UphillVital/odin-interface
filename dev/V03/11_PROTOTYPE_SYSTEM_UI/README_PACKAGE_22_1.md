# PACKAGE 22.1 — REAL PREVIEW UI

## Призначення

Цей пакет додає реальний внутрішній переглядач збірок у File Workspace.
Це вже не специфікація, а робочий UI-рівень.

## Що додано

- Кнопка `Переглянути / Preview / Vorschau` у панелі дій File Workspace.
- Preview Panel всередині центральної робочої колонки.
- Реальний HTML preview через `iframe` для `.html` / `.htm` файлів.
- Code/Text preview для `.md`, `.txt`, `.json`, `.js`, `.css` та інших текстових файлів.
- Інтеграція з UA / EN / DE.
- Інтеграція з Assisted Mode.

## Що не змінювалось

- Стиль Package 13.2.
- Layout Package 20.
- Quick Settings.
- Contextual Help.
- Workflow і File Workspace logic.
- Тема Light/Dark.

## Як тестувати

1. Відкрити `dev/V03/11_PROTOTYPE_SYSTEM_UI/index.html`.
2. Вибрати проєкт.
3. Перейти в `Робота з файлами`.
4. Завантажити `.html` файл або приклад.
5. Натиснути `Переглянути`.
6. Перевірити, що HTML показується реально в preview-панелі.
7. Для `.md` / `.txt` / `.json` перевірити текстовий/code preview.
8. Перемкнути UA / EN / DE і перевірити, що кнопка та підписи перекладаються.
9. Перемкнути Light/Dark і перевірити, що preview не ламає тему.

## Обмеження браузера

Браузер не має прямого доступу до локальної файлової системи. Preview працює з тим файлом, який користувач відкрив через File Picker або завантажив як приклад.
