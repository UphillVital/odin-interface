# PACKAGE INDEX WINDOW PREP v1

## Призначення

Цей документ готує майбутнє вікно `Package Index` у ODIN UI.

## Що має показувати Package Index

- номер пакету;
- назву пакету;
- статус;
- короткий опис;
- що додано;
- чи є README;
- чи є changelog-entry;
- дата інтеграції;
- посилання на робочі файли;
- посилання на службову папку `_packages/PACKAGE_<NUMBER>/`.

## Мінімальна таблиця

```text
Package | Назва | Статус | Опис | README | CHANGELOG | Робочі файли
```

## Майбутні дії

PACKAGE INDEX має стати окремим екраном ODIN UI, доступним через:

```text
Left Tree → System → Packages → Package Index
```
