# PROJECT WINDOWS v1

## Purpose

Each project needs its own controlled window model inside the ODIN Interface.

## Required Project Windows

### 1. Project Overview
Shows identity, status, current work, active workflows, and next recommended action.

### 2. Project Map
Shows structure and dependencies inside the project.

### 3. Modules
Lists project modules and their development status.

### 4. Files
Shows relevant project files, grouped by purpose.

### 5. Workflows
Shows available workflows, for example lesson creation, QA, export, package generation.

### 6. QA
Shows project-specific checks, warnings, failures, and locks.

### 7. Export / Package
Shows export-ready outputs and blocked outputs.

### 8. Documentation
Shows manuals, decisions, rules, and related specs.

## DT Project Windows

Deutsch Trainer should include:

- DT Overview
- ІССУ Workspace
- ССУДТ Workspace
- Unified Lesson Template
- Lesson QA
- Lesson Packages
- Translation System
- Highlight System
- Audio / Voice Practice

## Rule

No project window should modify files directly without passing through Change Control and QA.
