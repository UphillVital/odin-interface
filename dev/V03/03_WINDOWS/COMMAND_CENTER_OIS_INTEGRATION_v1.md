# Command Center — OIS Integration v1

## Purpose
Command Center is the visible control point for OIS Core.

## Must Display
- Active mode
- Active intent
- Active state
- Current target
- Next recommended action
- Blockers
- MASTER START status

## Primary Actions
- ODIN SYSTEM — MASTER START
- STATUS
- MAP
- QA
- EXPORT
- HELP

## Behavior
Command Center does not execute blindly. It routes actions through OIS Core.
