# ODIN V03 — Work Zone Types Matrix v1

| Zone | Primary Purpose | Activation | Shows | Main Actions | Output |
|---|---|---|---|---|---|
| Command Center | Global control | ODIN / CONTINUE / status request | state, mode, next step | continue, open map, master start | orientation |
| Master Start | Launch system/product workflow | button / MASTER START intent | product variants, checklist, pipeline | generate/start package | start package / workflow |
| System Map | Live architecture navigation | MAP / confusion / architecture | hierarchy, dependencies | inspect, navigate, explain | understanding + navigation |
| File Workspace | Work with files | edit/diff/approve/package | files, changes, diff | edit, approve, reject, package | controlled file changes |
| OIS | Interaction rules | commands/modes/state discussion | protocol, commands, modes | refine rules, lock terms | OIS spec |
| Build | Build/create | BUILD intent | task, inputs, plan | generate, handoff QA | artifact |
| QA | Validate quality | QA / after build / warnings | checks, fail/pass | inspect, request fix | QA report |
| Fix | Correct defects | bug / QA failed | issue, cause, affected modules | fix plan, safe patch | corrected system |
| Product | Product-specific work | product selected | product vision/modules | configure, inspect, build | product state |
| Manual / Assisted | Help and guidance | HELP / confusion | guidance, next steps | explain, guide, link | clarity |
| Experiments | Controlled innovation | experiment/new idea | hypothesis, risks | test, promote/reject | approved/rejected experiment |
