# I18N TEST CHECKLIST v1

## Goal
Confirm that the ODIN Interface translates fully across all user-visible areas.

## Languages
- UA
- EN
- DE

## Check areas
- Header
- MASTER START
- Theme button
- Language button
- Left navigation tree
- Command Center
- System Map
- Projects
- File Workspace
- Manual
- Tooltip `?` hints
- Assisted Mode panel
- Footer status bar

## Pass condition
The selected UI language must be consistent everywhere.

## Fail condition
Any visible mixed UA/EN/DE text in the same selected language mode is an I18N failure.
