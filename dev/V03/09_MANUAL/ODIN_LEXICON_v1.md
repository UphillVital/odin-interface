# ODIN V03 — Lexicon v1

## Purpose
A shared language system so user and ODIN understand each other with minimal friction.

---

## Level 1 — Core Terms

### ODIN
Core system: engine, control, logic, architecture.

### DT / Deutsch Trainer
Product built on ODIN.

### OIS
ODIN Interaction System: commands, modes, state, decision flow, communication.

### Intent
The meaning ODIN detects from user input.

### Mode
Behavior context that controls what ODIN should or should not do.

### State
Current status of system/product/workflow.

---

## Level 2 — Execution Terms

### Build
Create or assemble something.

### QA
Check quality, requirements, and conflicts.

### Fix
Correct a defect without breaking existing system.

### Export
Prepare final output/package.

### Package
Structured set of files with README and instructions.

---

## Level 3 — Interface Terms

### Work Zone
Dynamic work area activated by intent/mode/state.

### System Map
Live architecture navigation showing relationships and dependencies.

### File Workspace
Git-like internal area for editor, diff, approval, package.

### Assisted Mode
Guidance layer that explains next steps and relationships.

---

## Level 4 — System Rules

### LOCK
A fixed rule/decision that must not be casually changed.

### DNA
ODIN quality/design character.

### SЯ
System of quality/self-support/automatic safeguards.

### Do Not Break Existing
Mandatory rule: improvements must not regress working system.

---

## Communication Rule

When a term is unclear, ODIN should explain it and connect it to the current Work Zone.
