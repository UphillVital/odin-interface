ODIN Interface Manual v1

Що це?

ODIN Interface — це особистий кабінет керування системою ODIN.

Головна логіка

Інтерфейс допомагає бачити карту системи, працювати з файлами, запускати продукти, керувати OIS, QA, модулями та експериментами.

MASTER START

Кнопка ODIN SYSTEM — MASTER START повинна запускати правильний стартовий пакет за вибором продукту та системними правилами.

Робота з файлами

Редактор, зміни, diff, затвердження, відхилення, статуси та підготовка пакетів.
