# HOW TO USE ODIN EXPLANATIONS v1

## What explanations do
ODIN explanations help you understand where you are, what the selected area does, and what the next safe action is.

## Types
- `?` hints: short help near UI items.
- Zone help: explanation for the opened work area.
- Assisted Mode: guided next-step panel.
- Manual: detailed reference.

## User Rule
If something is unclear, open the `?` hint first, then read Assisted Mode.
