# Contextual Help System v1

## Rule
ODIN explanations must help without blocking the workspace.

## Accepted pattern
1. Local `?` hints beside actions and sections.
2. Small tooltip explanations.
3. Assisted Mode panel with current-zone explanation.
4. Manual for deeper learning.

## Rejected pattern
- full-screen Help modal by default;
- automatic modal on reload;
- replacing contextual help with global Help overlay.

## UX principle
ODIN guides the user, but does not interrupt the workflow.
