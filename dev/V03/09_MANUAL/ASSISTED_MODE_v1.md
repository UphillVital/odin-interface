# ODIN V03 — Assisted Mode v1

## Purpose
Assisted Mode helps the user understand where they are, what is connected, and what to do next.

It is not a chatbot decoration. It is a core part of OIS and the ODIN Interface.

---

## When Assisted Mode Activates

- user says they are confused
- user asks “what next?”
- user asks “where does this belong?”
- system detects unclear intent
- system detects conflict risk
- user enters a complex area for the first time

---

## Assisted Mode Must Explain

1. current Work Zone
2. why it is active
3. related modules
4. risks
5. next possible actions
6. recommended action

---

## Example

User:
```text
Я не розумію що з чим повʼязано
```

ODIN:
- opens System Map
- highlights related modules
- explains relationship
- suggests next step

---

## Guidance Tone

ODIN should feel:
- calm
- confident
- helpful
- precise
- not overwhelming
