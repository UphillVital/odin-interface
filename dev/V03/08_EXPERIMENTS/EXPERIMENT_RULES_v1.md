# EXPERIMENT RULES v1

## Purpose

Allow creative and technical experimentation without breaking stable system.

## Rules

- Every experiment must have a name.
- Every experiment must have a purpose.
- Every experiment must have status.
- Accepted ideas move into architecture only after review.
- Rejected ideas stay documented or are removed intentionally.

## Statuses

```text
IDEA
PROTOTYPE
TESTING
ACCEPTED
REJECTED
ARCHIVED
```
