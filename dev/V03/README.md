# ODIN Interface V03 — Controlled Modeling Zone

## Purpose

`dev/V03` is the controlled modeling zone for the next ODIN Interface architecture.

V03 is not a dump folder.  
V03 is a structured workspace where every file, screen, button, module, and decision must have a clear place in the system.

## Core Rule

V03 must not break V02.

- V02 = stable working base
- V03 = new architecture, modeling, interface structure, OIS, file workspace, experiments

## Main Direction

Build **ODIN Interface** as:

> Мій Кабінет управління в ОДІН

A personal organized control workspace for:
- system map
- navigation tree
- OIS
- products
- modules
- files
- decisions
- QA
- experiments
- documentation
- MASTER START workflows

## Folder Rules

Only add files that are:
1. needed
2. planned
3. documented
4. linked to architecture
5. connected to tree / windows / buttons / system logic

## Forbidden

Do not:
- move random old files here
- mix lesson templates with ODIN control interface
- create duplicate unclear versions
- add code before the screen/system purpose is defined
- break V02 behavior

## Required README Rule

Every package and major folder must contain README.md.
