# FILE WORKSPACE REAL v1

## Role
File Workspace is the ODIN area for controlled file work.

## Current supported level
- Load a local text file through browser picker.
- Edit draft.
- View original.
- View diff.
- Approve / Reject.
- Keep history.
- Download edited copy.

## Rule
File Workspace must operate in project context.

## Later levels
- Real filesystem bridge.
- Git diff integration.
- Package builder.
- QA gate before export.
