# Global Settings Menu Rules v1

## Рішення

Шестерня у шапці кожної сторінки є не тільки налаштуваннями, а входом у системне меню сторінки.

## Обовʼязкові елементи меню

- Головний інтерфейс;
- Commit Builder;
- State Workspace;
- Тема;
- Мова.

## Поведінка

- Меню має бути однаковим на всіх сторінках.
- Поточна сторінка має бути позначена активною.
- Тема і мова зберігаються через `localStorage`.
- UA / EN / DE мають працювати на всіх сторінках.

## Обмеження

Нові сторінки Інтерфейсу ОДІН повинні додаватись у глобальне меню, якщо вони є частиною системного workflow.
