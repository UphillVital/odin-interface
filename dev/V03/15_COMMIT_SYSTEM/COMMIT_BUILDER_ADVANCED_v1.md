# ODIN V03 — Advanced Commit Builder v1

## Призначення

Advanced Commit Builder створює повний набір фіксації змін після approve:

- `git add`
- `git commit`
- `git push`
- `git tag`
- `git push tag`
- запис для `dev/V03/CHANGELOG.md`

## Принцип

ODIN не виконує Git автоматично. ODIN генерує команди та changelog, а користувач копіює і виконує їх самостійно.

## Рівень автоматизації

- автопідстановка версії;
- автопідстановка slug для tag;
- генерація commit українською;
- генерація changelog українською;
- привʼязка до активного проєкту;
- привʼязка до workflow state;
- підказки, якщо зміни не approved.

## Правило якості

Commit Builder не повинен дозволяти створювати фінальний checkpoint без:

- версії;
- назви зміни;
- опису що зроблено;
- опису що це дає;
- контексту або причини фіксації.
