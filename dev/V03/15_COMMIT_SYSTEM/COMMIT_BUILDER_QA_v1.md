# Commit Builder QA v1

## Перевірки перед генерацією

1. Версія не порожня.
2. Назва зміни не порожня.
3. Є хоча б один пункт у “Що зроблено”.
4. Є хоча б один пункт у “Що це дає”.
5. Активний проєкт визначений або вказано “ODIN V03 Core”.
6. Workflow state бажано Approved.

## Якщо state не Approved

ODIN повинен показати попередження:

> Зміни ще не затверджені. Commit можна підготувати, але фіксацію краще робити після Approve.

## Заборони

- Не генерувати англомовний commit для V03.
- Не генерувати tag без версії.
- Не підміняти changelog короткою фразою.
- Не запускати Git автоматично.
