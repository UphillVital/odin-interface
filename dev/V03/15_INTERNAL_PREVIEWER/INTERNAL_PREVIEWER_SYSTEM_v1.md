# INTERNAL PREVIEWER SYSTEM v1

## Goal
ODIN must have an internal viewer for build outputs before packaging or release.

## First target formats
- HTML preview
- Markdown preview
- text/code preview
- JSON preview

## Required behavior
- Open generated file in a controlled preview area.
- Test before package/export.
- Keep Preview separated from Editor.
- Preview must not modify source content.

## HTML requirement
HTML files must be previewable as real rendered pages inside ODIN before final package acceptance.

## Future extension
The viewer should later support additional build artifacts and project-specific test modes.
