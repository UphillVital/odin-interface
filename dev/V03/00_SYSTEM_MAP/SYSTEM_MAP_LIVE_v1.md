# SYSTEM MAP LIVE v1

## Rule
System Map is not a static diagram. It is navigation.

## Required behavior
- Each visible node must represent a real system area.
- Clicking a node must activate the relevant Work Zone.
- The map must show relationships between OIS, Work Zones, File Workspace, Manual, and Master Start.

## Current prototype nodes
- OIS
- Command Center
- File Workspace
- Manual
