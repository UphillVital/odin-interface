# UI_COMPONENTS.md

## Базові компоненти ODIN UI

### Header
- логотип / назва системи;
- активний контекст;
- Quick Settings.

### Left Navigation
- System Map;
- Projects;
- Modules;
- Package Index;
- Manual.

### Center Work Area
- активна Work Zone;
- File Workspace;
- Preview;
- Commit Builder;
- Project workspace.

### Right Assisted Panel
- пояснення;
- next action;
- попередження;
- контекстні інструкції.

### Buttons
- однакова форма;
- зрозумілий текст;
- i18n;
- не дублювати одну й ту саму дію в різних місцях без причини.

### Status
- workflow;
- active project;
- QA;
- approved / review / changed.
