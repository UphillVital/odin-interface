# UI_RULES.md

## ODIN UI — основне правило

Усі сторінки Інтерфейсу ОДІН повинні мати єдину логіку, структуру і поведінку.

## Обовʼязково

- Єдина шапка.
- Єдина трьохколонкова структура.
- Єдина система кнопок.
- Єдина логіка Quick Settings.
- Єдина логіка підказок.
- Єдина поведінка тем.
- Єдина мультимовна система UA / EN / DE.
- Усі нові сторінки мають працювати за спільним layout-стандартом.

## Заборонено

- Робити окрему сторінку з іншим стилем.
- Додавати дублюючі кнопки в шапку.
- Створювати локальні рішення, які обходять загальні системи.
- Вставляти тексти без i18n.
- Ламати contextual help.
