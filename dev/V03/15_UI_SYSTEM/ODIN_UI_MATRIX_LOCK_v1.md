# ODIN UI Matrix Lock v1

## Призначення

`index.html` є еталонною матрицею дизайну для всіх сторінок Інтерфейсу ОДІН.

Усі службові сторінки повинні використовувати той самий базовий shell:
- шапка;
- логотип ODIN;
- кнопка шестерні справа;
- меню швидких налаштувань;
- перемикання теми;
- перемикання мов UA / EN / DE;
- триколонкова логіка;
- права панель пояснень;
- status bar.

## Заборонено

- створювати окрему шапку для службової сторінки;
- змінювати кольори локально без оновлення матриці;
- робити окреме меню налаштувань;
- приховувати переходи між службовими сторінками;
- створювати сторінку, яка виглядає не як ODIN Interface.

## Правило

Якщо службова сторінка не виглядає як `index.html`, пакет має статус `QA_FAILED`.
