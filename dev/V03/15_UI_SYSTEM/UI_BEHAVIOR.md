# UI_BEHAVIOR.md

## Поведінка інтерфейсу

Інтерфейс ODIN має допомагати, а не заважати.

## Принципи

- Користувач завжди бачить, де він знаходиться.
- Користувач розуміє, який проєкт активний.
- Користувач бачить workflow-статус.
- Підказки не перекривають роботу.
- Preview доступний до збереження.
- File Workspace працює тільки в контексті активного проєкту.

## Contextual Help

Підказки повинні бути локальними:
- маленькі `?`;
- tooltips;
- пояснення в Assisted Panel.

Глобальні help-модалки не є базовою моделлю ODIN.

## Workflow

Базовий цикл:

```text
Project → File → Edit → Diff → Preview → QA → Approve → Save
```
