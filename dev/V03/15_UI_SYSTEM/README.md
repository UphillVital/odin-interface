# ODIN V03 — UI Design System Lock

Цей розділ фіксує правила інтерфейсу ODIN V03.

Мета: зберегти стабільну основу інтерфейсу після формування робочого середовища:
- fixed header;
- три основні колонки;
- окрема прокрутка;
- стабільна поведінка File Workspace / Preview / Assisted Mode;
- єдиний стиль для всіх сторінок.

Цей пакет НЕ змінює робочий UI. Він фіксує правила, яких треба дотримуватись у наступних пакетах.
