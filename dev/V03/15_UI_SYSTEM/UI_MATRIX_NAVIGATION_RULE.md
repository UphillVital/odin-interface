# ODIN V03 — UI Matrix Navigation Rule

## Правило

Перша колонка навігації на всіх сторінках Інтерфейсу ОДІН повинна відповідати головній сторінці.

## Що має бути однаковим

- тип елементів: кнопки / nav items;
- порядок груп;
- spacing;
- hover / active стан;
- розміри;
- кольори;
- поведінка прокрутки;
- i18n для назв.

## Дозволено

Службова сторінка може мати активний пункт меню відповідно до себе:

```text
Commit Builder → active on commit_builder.html
State Workspace → active on state_workspace.html
```

## Заборонено

- робити іншу навігацію для службових сторінок;
- робити ліву колонку коротшою або іншою за стилем;
- прибирати системні пункти навігації.
