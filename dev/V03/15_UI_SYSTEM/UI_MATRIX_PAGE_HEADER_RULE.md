# ODIN V03 — UI Matrix Page Header Rule

## Правило

`index.html` є еталонною дизайн-матрицею для всіх сторінок Інтерфейсу ОДІН.

Кожна окрема сторінка повинна повторювати шапку головної сторінки за структурою, кольорами, відступами, логотипом, кнопкою налаштувань і поведінкою.

## Єдина структура шапки

На головній сторінці:

```text
ODIN
Інтерфейс ОДІН
Робоче середовище керування системою
```

На службовій сторінці:

```text
ODIN
Інтерфейс ОДІН
<НАЗВА СТОРІНКИ>
```

## Заборонено

- робити окрему шапку для Commit Builder;
- робити окрему шапку для State Workspace;
- міняти логіку Quick Settings;
- міняти стиль першої навігаційної колонки;
- створювати сторінки без відповідності `index.html`.

## QA правило

Якщо службова сторінка не повторює головний UI Shell 1:1, пакет отримує статус:

```text
QA_FAILED — UI_MATRIX_MISMATCH
```
