# UI_RESTRICTIONS.md

## Що не можна ламати

- Fixed header.
- Триколонкову структуру.
- Окрему прокрутку колонок.
- Quick Settings.
- UA / EN / DE.
- Light default + Dark.
- Contextual help.
- File Workspace.
- Preview UI.
- Workflow indicator.

## Що можна змінювати після цього LOCK

Дозволено тільки контрольований Visual Polish:
- кольори;
- hover-ефекти;
- дрібні відступи;
- мікроанімації;
- іконки.

Але тільки якщо це не змінює layout, поведінку і загальну логіку.
