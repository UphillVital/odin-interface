# GLOBAL ODIN UI MATRIX RESTORE — v27.2

## Рішення
`index.html` є еталонною матрицею дизайну Інтерфейсу ОДІН. Усі окремі сторінки повинні повторювати його shell: шапку, першу колонку, меню шестерні, теми, мови, кольори й поведінку.

## Закон для всіх сторінок
Жодна сторінка Інтерфейсу ОДІН не має права мати власний локальний layout.

## Формат шапки
- ODIN
- Інтерфейс ОДІН
- Назва поточної сторінки

## Перша колонка
Перша колонка на всіх сторінках використовує стиль кнопок головного інтерфейсу, а не прості текстові посилання.

## Меню шестерні
Меню шестерні на всіх сторінках має містити однакову системну навігацію та налаштування.
