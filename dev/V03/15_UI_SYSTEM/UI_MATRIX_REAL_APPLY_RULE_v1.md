# UI MATRIX REAL APPLY RULE v1

## Закон

`index.html` є еталонною UI Matrix для всіх сторінок Інтерфейсу ОДІН.

## Header

Кожна сторінка повторює структуру:

```text
ODIN
Інтерфейс ОДІН
<НАЗВА СТОРІНКИ>
```

Для головної сторінки третій рядок:

```text
Робоче середовище керування системою
```

## Left navigation

Перша колонка на всіх сторінках має повторювати кнопки головного Інтерфейсу ОДІН.

## Quick Settings

Кнопка шестерні має бути на кожній сторінці та містити переходи до системних сторінок.

## QA

Якщо сторінка має власний локальний header, власну навігацію або власний стиль — `QA_FAILED`.
