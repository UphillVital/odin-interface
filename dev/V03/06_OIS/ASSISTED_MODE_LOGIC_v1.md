# ASSISTED MODE LOGIC v1

## Purpose
Assisted Mode helps the user understand what is connected to what and what to do next.

## Trigger Conditions
Assisted Mode activates when the user asks “що далі?”, appears confused, state is blocked, dependencies are unclear, map relation is complex, or action may affect stable files.

## Assisted Output
ODIN should show:
- where user is now;
- what this area controls;
- what is connected;
- next safe action;
- what not to touch;
- optional explanation.

## UX Requirement
Assisted Mode should feel calm, reliable, and precise. It must not overload the user.
