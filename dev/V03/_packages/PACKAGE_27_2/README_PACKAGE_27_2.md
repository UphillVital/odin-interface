# PACKAGE 27.2 — REAL UI MATRIX APPLY

## Призначення

Цей пакет реально застосовує закон UI Matrix до службових сторінок Інтерфейсу ОДІН.

## Що виправлено

- `commit_builder.html` повторює shell головної сторінки `index.html`.
- `state_workspace.html` повторює shell головної сторінки `index.html`.
- У шапці службових сторінок структура така сама:
  - `ODIN`
  - `Інтерфейс ОДІН`
  - `<НАЗВА СТОРІНКИ>`
- Ліва колонка навігації повторює головну сторінку 1:1.
- Кнопка шестерні та popup-меню залишаються єдиною системною точкою навігації.

## Що не змінювалось

- логіка File Workspace;
- Preview UI;
- State System;
- Commit Builder логіка генерації;
- основний стиль 13.2.

## Тестування

Відкрити:

```text
dev/V03/11_PROTOTYPE_SYSTEM_UI/index.html
dev/V03/11_PROTOTYPE_SYSTEM_UI/commit_builder.html
dev/V03/11_PROTOTYPE_SYSTEM_UI/state_workspace.html
```

Перевірити:

- шапка однакова за структурою;
- різниться тільки назва сторінки в третьому рядку;
- ліва колонка має ті самі кнопки, що головна сторінка;
- шестерня відкриває однакове меню;
- UA/EN/DE працює;
- Light/Dark працює.
