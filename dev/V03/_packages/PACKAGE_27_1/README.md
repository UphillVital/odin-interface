# PACKAGE 27.1 — UI MATRIX HEADER + NAVIGATION COMPLIANCE FIX

## Призначення

Пакет виправляє рецидив порушення UI Design System Lock після Package 27.

## Проблема

Службові сторінки:

- `commit_builder.html`
- `state_workspace.html`

не відповідали головній сторінці `index.html` на 100%:

- ліва колонка навігації / кнопок не повторювала головну;
- шапка не повторювала структуру головної;
- замість єдиного ODIN Shell сторінки все ще виглядали як окремі шаблони.

## Рішення

1. Зафіксовано правило єдиної шапки:

```text
ODIN
Інтерфейс ОДІН
<НАЗВА СТОРІНКИ>
```

2. Зафіксовано правило єдиної першої колонки навігації.
3. Додано QA-правила для перевірки відповідності службових сторінок матриці `index.html`.

## Важливо

Цей пакет не повинен змінювати логіку Commit Builder або State Workspace.
Він фіксує вимоги до шаблону і готує коректне виправлення UI Matrix.
