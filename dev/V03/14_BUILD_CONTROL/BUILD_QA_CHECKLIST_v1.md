# Build QA Checklist v1

Before marking a snapshot stable, check:

- Header remains fixed.
- Three-column layout scrolls independently.
- Theme switching works.
- Language switching works globally.
- Contextual hints work.
- File Workspace editor works.
- Original panel is read-only.
- Editor / Original comparison remains synchronized.
- Project selection is visible.
- Workflow states update.
- No global Help modal regression.
- No empty package folders.
- README exists.
