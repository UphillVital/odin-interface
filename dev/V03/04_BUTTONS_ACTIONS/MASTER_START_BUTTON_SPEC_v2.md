# MASTER START Button Spec v2

## Button Label

```text
ODIN SYSTEM — MASTER START
```

## Role
Primary system action.

## Button States
`READY`, `PRODUCT_REQUIRED`, `SCENARIO_READY`, `VALIDATION_FAILED`, `RUNNING`, `QA_PENDING`, `EXPORT_READY`, `BLOCKED`, `DESIGNED_NOT_CONNECTED`

## Interaction
Click opens a guided Work Zone with product selector, scenario selector, rules preview, pipeline preview, and run/confirm action.

## Visual Requirement
The button must feel important, calm, and trustworthy. It should not be aggressive or chaotic.
