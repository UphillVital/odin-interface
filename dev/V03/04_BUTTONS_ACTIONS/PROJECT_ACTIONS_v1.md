# PROJECT ACTIONS v1

## Purpose

Project-level actions must be explicit and controlled.

## Required Actions

### Open Project
Activates the project workspace.

### Create New Project
Creates a planned project entry. It must not generate full structure without confirmation.

### Open Project Map
Shows dependencies and modules.

### Open Files
Activates File Workspace scoped to the selected project.

### Run QA
Runs project-specific checks.

### Build Package
Creates package only if QA allows it.

### MASTER START for Project
Starts a project-specific workflow.

## Rule

All actions must show:

- current state
- expected result
- risk level
- next step
