# DESIGN RESTRICTIONS v1

## Forbidden
- copy Lesson UI directly into System UI
- overload interface with unrelated blocks
- create alternative templates without conflict check
- hide system state
- use visual style that contradicts ODIN DNA

## Required
- clarity
- hierarchy
- calm control
- readable work zones
- dark and light themes
- system-map-based navigation
- assisted mode where the user may be lost

## Template Conflict QA
Before the first prototype is accepted, check:
- no conflict with Lesson Template
- no broken DT product assumptions
- no duplicate system logic
- no parallel uncontrolled UI standard
