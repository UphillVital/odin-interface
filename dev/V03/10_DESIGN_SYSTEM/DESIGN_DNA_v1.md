# ODIN DESIGN DNA v1

## Core Principle
ODIN does not produce poor-quality work.

## Design Feeling
ODIN products and interfaces must feel:
- calm
- clear
- controlled
- confident
- reliable
- light
- refined
- kind
- high-quality

## System Meaning
Design is not decoration. Design is system behavior made visible.

## UX Promise
The user must:
- not get lost
- understand the current state
- see the next safe action
- feel that ODIN supports the work
- trust that changes are controlled

## Automation Principle
Every ODIN interface should support maximum reasonable self-supporting automation without hiding critical decisions from the user.

## Forbidden
- chaotic UI
- aggressive visual noise
- unclear actions
- hidden state
- fake system behavior
- decorative components with no function
