# UI LAYERS v1

## Level 1 — System UI
ODIN Interface / Control workspace.
Purpose: manage system, work zones, files, states, actions, QA, packages.

## Level 2 — Product UI
Deutsch Trainer and future ODIN products.
Purpose: product-specific user experience.

## Level 3 — Lesson UI
Lesson template, learning content, translations, highlights, audio and practice.

## Rule
UI layers must not be mixed.
Lesson UI can inspire ODIN DNA and CSS direction, but ODIN Interface must remain a system-control interface.
