# ODIN DESIGN DNA v1

Status: mandatory design philosophy for ODIN products.

---

## 1. ODIN Must Feel Like

- light;
- refined;
- calm;
- confident;
- kind;
- reliable;
- high-quality;
- intelligent;
- supportive;
- systematic.

ODIN does not do poor work.

---

## 2. Design Direction

ODIN visual language should express:

- AI;
- advanced technology;
- friendship between people and modern technologies;
- development of artificial models;
- human-AI cooperation in everyday work.

---

## 3. Theme Rule

Every ODIN product must have at minimum:

```text
Dark Theme
Light Theme
```

This is a platform rule, not a preference.

---

## 4. Lesson Template as DNA

The lesson template may inspire:

- calm design;
- header idea;
- card rhythm;
- readable blocks;
- flexible CSS structure;
- refined spacing.

But lesson UI and system UI must remain separate layers.

---

## 5. Forbidden Visual Direction

Avoid:

- aggressive cyberpunk overload;
- chaotic panels;
- too many bright accents;
- unclear button hierarchy;
- fake futuristic decoration without usability;
- visual noise.

---

## 6. Required Feeling

The user should feel:

```text
I understand where I am.
I know what is connected.
I see the next step.
The system protects my work.
```
