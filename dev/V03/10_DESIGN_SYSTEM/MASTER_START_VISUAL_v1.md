# MASTER START VISUAL v1

## Role
ODIN SYSTEM — MASTER START is the primary system action.

## Purpose
It launches the correct ODIN workflow based on selected product/system variant and rules.

## Must Show
- selected product/system variant
- scenario
- readiness state
- workflow preview
- execution state
- result or blocker

## Visual Requirements
- visible in the main header
- not hidden inside secondary menus
- visually important but calm
- must not look like a normal small button

## Rule
MASTER START is the entry point to controlled system execution.
