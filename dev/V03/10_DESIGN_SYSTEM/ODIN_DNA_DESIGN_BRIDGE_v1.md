# ODIN V03 — DNA Design Bridge v1

## Purpose
Connects ODIN's design philosophy to the Work Zone System.

---

## ODIN Feeling

Anything created by ODIN should feel:

```text
light
refined
calm
confident
kind
reliable
high-quality
```

---

## Interface Implication

Work Zones must not feel like isolated admin pages.
They must feel like controlled spaces for serious work.

---

## Design Rule

Lesson UI may inspire the ODIN Interface, but must not be copied blindly.

```text
Lesson UI ≠ System UI
```

We may reuse:
- CSS DNA
- calm typography
- refined spacing
- header inspiration
- visual softness

We must redesign:
- layout
- navigation
- work zones
- state panels
- file workspace
- system map

---

## Theme Rule

All ODIN products must support at least:

1. Dark Theme
2. Light Theme

Dark may be default for system control.
Light must exist as a first-class supported theme.
