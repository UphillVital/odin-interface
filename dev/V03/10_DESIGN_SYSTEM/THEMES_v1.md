# THEMES v1

## LOCK RULE
All ODIN products must support at least two themes:

1. Dark Theme
2. Light Theme

## Default
Dark Theme may be the default for system interfaces.
Light Theme must remain fully supported.

## Requirements
- Same layout in both themes
- No logic change between themes
- No layout shift when switching themes
- High readability and contrast
- Calm colors, no aggressive saturation

## Forbidden
- different UI structure per theme
- theme-specific behavior
- hidden controls in one theme
