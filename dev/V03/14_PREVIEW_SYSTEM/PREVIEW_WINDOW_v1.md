# PREVIEW WINDOW v1

## Призначення

Preview Window — окрема робоча зона для перегляду результатів файлів та збірок.

## Блоки

1. Preview Toolbar
   - назва файлу
   - тип файлу
   - кнопка оновлення перегляду

2. Preview Surface
   - iframe для HTML
   - pre/code для текстових форматів

3. Preview Status
   - Ready
   - Preview generated
   - Unsupported format
   - Error

## UX правило

Preview має бути спокійним, чистим і не перекривати інтерфейс.
