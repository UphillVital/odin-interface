# ODIN V03 — PACKAGE 22: INTERNAL BUILD PREVIEWER

## Призначення

Цей пакет додає системну специфікацію внутрішнього переглядача збірок перед збереженням або затвердженням.

## Куди розпаковувати

Розпакувати ZIP у корінь репозиторію:

```text
C:\Users\Vitalii\OneDrive\Документы\GitHub\odin-interface\
```

## Що додається

```text
dev/V03/14_PREVIEW_SYSTEM/
├─ README.md
├─ PREVIEW_ENGINE_v1.md
├─ PREVIEW_WINDOW_v1.md
├─ PREVIEW_RULES_v1.md
└─ PREVIEW_UI_SPEC_v1.md
```

Також додаються sync-файли для карти, архітектури та дерева.

## Як тестувати після майбутньої UI-інтеграції

1. Відкрити File Workspace.
2. Завантажити або вставити HTML.
3. Натиснути Preview / Переглянути.
4. Переконатися, що HTML відкрився у внутрішній зоні перегляду.
5. Після перевірки перейти до Review / Approve.

## Важливо

Цей пакет не ламає поточний інтерфейс. Він додає архітектурний модуль Preview System і готує основу для повної UI-інтеграції.
