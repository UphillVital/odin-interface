# PREVIEW ENGINE v1

## Призначення

Internal Build Previewer — це внутрішній переглядач збірок ODIN перед збереженням, затвердженням або пакуванням.

## Основний принцип

Користувач не повинен зберігати або затверджувати результат, поки не побачить його у реальному перегляді.

## Підтримувані формати v1

- HTML — реальний перегляд через sandbox iframe.
- Markdown / TXT — текстовий перегляд.
- JSON — форматований перегляд.
- JS / CSS / CODE — текстовий перегляд із моноширинним форматуванням.

## Потік

```text
Edit → Preview → Test → Approve → Save / Download
```

## Правила

1. Preview не замінює QA.
2. Preview не зберігає файл автоматично.
3. Preview працює тільки як контроль перед затвердженням.
4. HTML відкривається у sandbox-зоні.
5. Помилки preview не повинні ламати File Workspace.
