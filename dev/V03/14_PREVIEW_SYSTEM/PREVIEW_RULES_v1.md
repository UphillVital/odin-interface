# PREVIEW RULES v1

## Обов'язково

- Перед затвердженням HTML-збірки користувач має мати можливість її переглянути.
- Preview не повинен змінювати оригінальний файл.
- Preview має працювати з поточним вмістом редактора.
- Preview має бути доступний у контексті File Workspace.

## Заборонено

- Автоматично зберігати файл після preview.
- Підміняти QA візуальним переглядом.
- Відкривати нові хаотичні вікна без потреби.
- Ламати існуючі теми, i18n, Quick Settings або contextual help.
