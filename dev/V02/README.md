## Як перевірити

1. Відкрий:

```text
dev/V02/index.html
```

2. Натисни:

```text
AUTO SELECT
```

3. Перевір, що SESSION заповнився.

4. У полі `Тема уроку` введи тему.

5. Натисни:

```text
GENERATE LESSON
```

6. Перевір, що в `Generated Lesson Preview` зʼявився HTML.

7. Натисни:

```text
DOWNLOAD HTML
```
