# TEST — ODIN V03.7.1.1 MAP EXPANSION

## Передумова

У V03.7.1 було:

```text
Total Files: 182
Mapped: 68
Unmapped: 114
```

---

## Запуск

Відкрити:

```text
http://127.0.0.1:5500/dev/V02/admin.html
```

---

## Кроки

1. Знайти блок `File Control Map Expanded`.
2. Натиснути `REFRESH MAP`.
3. Перевірити:
   - Total Files > 0
   - Mapped значно більше ніж 68
   - Unmapped значно менше ніж 114
4. Перевірити, що зʼявились групи:
   - 00 CORE SYSTEM
   - 04 QA SYSTEM
   - 05 LESSON SYSTEM
   - 07 UNIFIED LESSON TEMPLATE
   - 08 HIGHLIGHT SYSTEM
   - 09 TRANSLATION SYSTEM
   - 14 WORKFLOW SYSTEM
   - 16 RULES SYSTEM

---

## Очікувано

ODIN починає розуміти власну системну структуру.
