# USER FORMAT RULES

## Що це
Правила формату відповідей для Віталія.

## Обовʼязково
- готові файли;
- пакети;
- коротке пояснення;
- куди класти;
- Git у стилі PUSH;
- без води;
- не перепитувати зайве;
- якщо є ризик — попередити.

## Заборонено
- “встав десь у main”;
- давати неповний файл замість пакета;
- міняти формат без потреби;
- замінювати 320 рядків на 80 рядків.

## Правило
Формат має допомагати не помилитись.
