# ODIN GLOBAL RULES

## Що це
Глобальні правила всієї системи ОДІН.

## Призначення
- тримати якість;
- не ламати стабільні рівні;
- не вигадувати еталони;
- працювати пакетами;
- давати користувачу готовий результат.

## Головний принцип
```text
Не вигадувати. Не ламати. Фіксувати. Працювати пакетами.
```
