# STOP AND ROLLBACK RULE

## Що це
Правило зупинки при хаосі.

## Коли застосовувати
- якщо пішов бардак;
- якщо змішались файли;
- якщо Git показує небажані файли;
- якщо зʼявився ризик зламати stable.

## Дії
1. STOP;
2. git status;
3. unstage зайве;
4. clean untracked, якщо треба;
5. повернутись до stable;
6. продовжити тільки через пакет.

## Правило
Зупинка — це не провал, а захист системи.
