# GIT PUSH STYLE RULE

## Що це
Стандарт подачі Git-команд.

## Формат
```text
🚀 VS CODE GIT
```

## Приклад
```bash
git add ODIN_TREE_PROJECT_v1/16_RULES/
git commit -m "v3.40 add ODIN global rules documentation"
git push origin dev
```

## Заборонено
- давати нечіткі команди;
- змішувати Git і JavaScript;
- писати “десь додай”;
- радити `git add .`, коли є untracked сміття.

## Правило
Git-команди мають бути короткі, точні, готові до вставки.
