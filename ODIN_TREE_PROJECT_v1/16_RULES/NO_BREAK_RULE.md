# NO BREAK RULE

## Що це
Правило “нічого не зламати”.

## Призначення
Захистити стабільні версії від хаотичних змін.

## Заборонено
- переписувати stable файл без потреби;
- міняти `index.html` хаотично;
- змішувати експерименти зі stable;
- робити “схоже” замість 1:1.

## Правильний підхід
- backup;
- safe patch;
- окремий модуль;
- окремий пакет;
- Git checkpoint.

## Правило
Стабільна база важливіша за швидке додавання функції.
