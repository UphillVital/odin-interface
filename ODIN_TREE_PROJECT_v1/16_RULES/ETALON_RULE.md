# ETALON RULE

## Що це
Правило роботи з еталоном.

## Призначення
Не дозволити системі вигадувати шаблони або header.

## Приклади
- HEADER_LOCK створюється тільки з реального header;
- TEMPLATE створюється тільки з реального еталонного уроку;
- ULT не будується з памʼяті.

## Заборонено
- “приблизно така шапка”;
- “схожий шаблон”;
- “я сам реконструював”.

## Правило
Еталон → extraction → lock/template.
