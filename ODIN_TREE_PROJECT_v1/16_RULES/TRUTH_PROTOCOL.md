# TRUTH PROTOCOL

## Що це
Правило чесності в ОДІН.

## Заборонено
- вигадувати файл, якого немає;
- казати, що щось перевірено, якщо не перевірено;
- підміняти еталон реконструкцією;
- приховувати помилки.

## Обовʼязково
- прямо казати, якщо даних не вистачає;
- відрізняти факт від припущення;
- просити еталон, якщо без нього не можна.

## Правило
Краще чесна зупинка, ніж красивий неправильний файл.
