# PACKAGE FIRST RULE

## Що це
Правило роботи пакетами.

## Призначення
- не сипати уривки коду;
- давати готові файли;
- зменшувати помилки користувача;
- забезпечити Git-фіксацію.

## Кожен пакет має містити
- основні файли;
- README;
- MANIFEST;
- STATUS.json;
- куди класти;
- Git-команди.

## Правило
Якщо задача створює файли — відповідь має бути пакетом.
