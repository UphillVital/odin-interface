# PACKAGE TYPES

## Основні типи пакетів
- DOCS PACKAGE — документація;
- MODULE PACKAGE — JS / логічні модулі;
- TEMPLATE PACKAGE — шаблони;
- TOOL PACKAGE — HTML інструменти;
- RECOVERY PACKAGE — відновлення системи;
- RELEASE PACKAGE — стабільний реліз.

## Правило
Тип пакета має бути зрозумілий з назви.
