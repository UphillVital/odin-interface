# PACKAGE STRUCTURE

## Мінімальна структура
- основні файли;
- README;
- PACKAGE_MANIFEST;
- PACKAGE_STATUS.json;
- Git instructions.

## Для HTML / tools
- основний `.html`;
- README;
- STATUS;
- QA notes.

## Для docs
- `.md` файли;
- README;
- MANIFEST;
- STATUS.

## Правило
Пакет без README або MANIFEST не вважається завершеним.
