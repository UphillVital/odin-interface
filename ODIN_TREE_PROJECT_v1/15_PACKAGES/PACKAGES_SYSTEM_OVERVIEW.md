# ODIN PACKAGES SYSTEM

## Що це
Система пакетної роботи ODIN.

## Призначення
- збирати зміни в контрольовані пакети;
- не розкидати файли хаотично;
- давати користувачу готові artifact-и;
- забезпечити відтворення і Git-фіксацію.

## Основний принцип
Пакет = одиниця роботи.

## Кожен пакет має відповідати на питання
- що це?
- куди класти?
- що всередині?
- як перевірити?
- як запушити?
