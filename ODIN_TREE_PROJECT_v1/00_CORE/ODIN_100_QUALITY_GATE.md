# ODIN 100% QUALITY GATE

## Що це
Фінальний контроль якості перед фіксацією продукту або модуля.

## Призначення
- не пропускати сирий результат;
- виявляти помилки до Git push;
- відділяти demo від stable;
- гарантувати рівень 100%.

## Перевірки
- структура;
- UI;
- функціональність;
- QA;
- інтеграції;
- export;
- Git status;
- відповідність еталону.

## Статуси
- QA_PASSED;
- QA_PASSED_WITH_WARNINGS;
- QA_FAILED;
- EXPORT_READY;
- FIX_REQUIRED.

## Правило
Якщо продукт не пройшов gate — він не фіксується як stable.
