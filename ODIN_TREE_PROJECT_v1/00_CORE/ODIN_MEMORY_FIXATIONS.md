# ODIN MEMORY / ФІКСАЦІЇ

## Що це
Система збереження прийнятих рішень, стабільних версій і правил.

## Призначення
- фіксувати стабільні точки;
- не втрачати рішення між чатами;
- відтворювати систему після збою;
- не повторювати старі помилки.

## Структура
- Fixed Versions;
- Decisions;
- Rules;
- Checkpoints;
- Stable Packages;
- Recovery Prompts;
- Git commits.

## Приклади фіксацій
- ODIN_INTERFACE v3.22 = BASE;
- HEADER_LOCK_v1 = окремий lock-модуль;
- QA Engine v2 = stable lesson QA;
- ULT_v1 = скасовано, бо був не з еталону.

## Правило
Якщо рішення не зафіксоване — воно не є частиною системи.
