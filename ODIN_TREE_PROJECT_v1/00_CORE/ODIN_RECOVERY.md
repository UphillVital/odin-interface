# ODIN RECOVERY

## Що це
Система відновлення ОДІН після збоїв, втрати контексту або переходу в новий чат.

## Призначення
- відновити систему без втрат;
- швидко повернутись до стабільної точки;
- зберегти командну синхронізацію;
- запустити ОДІН з правильного стану.

## Структура
- MASTER_START;
- RECOVERY PACK;
- SYSTEM STATUS;
- FIXED BASE;
- CHECKPOINTS;
- Git restore commands.

## Режими запуску
- ODIN — базова активація;
- ODIN + version — активація конкретної стабільної версії;
- ODIN+VITALII — повна система за домовленістю.

## Правило
Recovery має відновлювати не тільки файли, а й логіку: що є базою, що є модулем, що скасовано.
