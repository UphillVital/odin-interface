# ODIN CORE

## Що це
ODIN CORE — логічне ядро всієї системи ОДІН.

## Призначення
- координує всі підсистеми;
- задає правила роботи;
- тримає цілісність системи;
- визначає, що є базою, що є модулем, а що є результатом.

## Структура
- Core Engine — логіка роботи;
- State Manager — поточний стан системи;
- Module Bridge — зв’язок із модулями;
- Execution Control — керування процесами;
- Quality Gate Binding — зв’язок із QA та 100% Gate.

## Роль у системі
CORE не є UI, не є уроком і не є окремим модулем.  
CORE — це центр прийняття логічних рішень.

## Правило
Будь-який новий рівень ОДІН має проходити через CORE:
СОН → PLAN → BUILD → QA → FIX → EXPORT → PUSH → FIXATION.
