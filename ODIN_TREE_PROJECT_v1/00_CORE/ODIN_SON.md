# ODIN СОН (Deep Analysis Mode)

## Що це
СОН — режим глибокого аналізу перед виконанням.

## Призначення
- не стрибати в код без плану;
- знайти причину проблеми;
- відділити симптом від архітектурної помилки;
- побудувати безпечний план.

## Процес
1. Діагноз;
2. Виявлення ризиків;
3. Розділення бази і модулів;
4. План safe-пакета;
5. Тільки потім виконання.

## Коли застосовувати
- перед зміною інтерфейсу;
- перед створенням шаблону;
- перед інтеграцією модулів;
- перед відновленням системи;
- коли починається хаос.

## Правило
Без СОН — ризик хаосу.  
З СОН — контроль, план, пакет, фіксація.
