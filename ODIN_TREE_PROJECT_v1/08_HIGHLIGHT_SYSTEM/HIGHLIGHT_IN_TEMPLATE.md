# HIGHLIGHT IN TEMPLATE

## Де живе підсвітка
У шаблоні уроку підсвітка живе в німецьких реченнях:

```html
<div class="de">
  <span class="lm-word ...">...</span>
</div>
```

## Звʼязок із TEMPLATE
Єдиний шаблон уроку має містити:
- CSS для highlight;
- JS для glow toggle;
- класи `lm-*`;
- data-атрибути;
- QA markers.

## Правило
TEMPLATE не повинен прибирати markup, навіть якщо контент змінюється.
