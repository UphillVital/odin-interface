# ODIN HIGHLIGHT SYSTEM

## Що це
Система підсвітки німецького тексту в уроках ODIN / Deutsch Trainer.

## Призначення
- допомогти бачити граматичну структуру речення;
- виділяти ключові слова теми;
- підтримувати режими підсвітки;
- працювати разом із QA та Markup Accuracy Engine.

## Основні шари
- Topic highlight;
- Grammar highlight;
- Language markup;
- LM tags;
- Case / gender / POS markup;
- Lamp toggle modes.

## Базове правило
Підсвітка не повинна бути просто кольором.  
Вона має нести дані: lemma, pos, case, role, accuracy.
