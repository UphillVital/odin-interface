# CLERK / ДІЛОВОД PROTOCOL

## Що це
Роль ведення документів.

## Призначення
- мати актуальний список файлів;
- знати що де лежить;
- підтримувати структуру документів;
- фіксувати пакети.

## Обовʼязки
- file registry;
- package list;
- status list;
- актуальні README.

## Правило
Документи мають бути в актуальному стані.
