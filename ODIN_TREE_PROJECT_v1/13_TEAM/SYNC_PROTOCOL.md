# SYNCHRONIZATION PROTOCOL

## Що це
Правила синхронізації команди.

## Синхронізація означає
- знати поточний стан;
- знати останнє рішення;
- не діяти по старій інформації;
- фіксувати зміни.

## Фраза
`Я в курсі справ. Синхронізований.`

## Правило
Перед важливим виконанням команда має бути синхронізована.
