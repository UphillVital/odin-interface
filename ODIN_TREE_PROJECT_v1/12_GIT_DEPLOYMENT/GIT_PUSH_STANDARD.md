# GIT PUSH STANDARD

## Стандарт команд ODIN

```bash
git add <path>
git commit -m "message"
git push origin dev
```

## Правило
Не використовувати `git add .`, якщо є зайві untracked files.

## Приклад
```bash
git add ODIN_TREE_PROJECT_v1/12_GIT_DEPLOYMENT/
git commit -m "v3.36 add ODIN git deployment documentation"
git push origin dev
```
