# СОН STAGE

## Що це
СОН — глибокий аналіз перед дією.

## Призначення
- зрозуміти проблему;
- знайти ризики;
- не плутати симптом з причиною;
- побудувати безпечний план.

## Вхід
- запит користувача;
- поточний стан системи;
- файли / еталони;
- попередні фіксації.

## Вихід
- діагноз;
- план;
- список ризиків;
- рішення: робити / не робити / чекати еталон.
