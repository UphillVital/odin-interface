# PLAN STAGE

## Що це
План виконання після СОН.

## Призначення
- розкласти роботу на кроки;
- визначити файли;
- визначити куди класти;
- визначити Git-команди.

## План має містити
- target folder;
- package name;
- expected files;
- test steps;
- push commands.

## Правило
План має бути достатньо чітким, щоб не питати “куди це класти?”.
