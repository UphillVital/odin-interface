# ODIN WORKFLOW ENGINE

## Що це
Workflow Engine — процесна система ОДІН.

## Призначення
- не дозволяти хаотичні дії;
- вести роботу від ідеї до зафіксованого результату;
- забезпечувати 100% якість;
- тримати порядок між пакетами, тестами і Git.

## Головний цикл
```text
СОН → PLAN → BUILD → TEST → QA → FIX → EXPORT → PUSH → FIXATION
```

## Правило
Будь-яка важлива зміна проходить через workflow.
