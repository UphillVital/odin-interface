# BUILD STAGE

## Що це
Створення файлів або пакетів.

## Призначення
- зібрати готовий artifact;
- не давати користувачу уривки;
- створювати повні файли.

## Види build
- documentation package;
- HTML tool;
- module package;
- template package;
- recovery package.

## Правило
Краще один готовий пакет, ніж багато тексту в чаті.
