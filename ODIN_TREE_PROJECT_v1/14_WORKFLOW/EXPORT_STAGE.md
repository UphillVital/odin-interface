# EXPORT STAGE

## Що це
Підготовка результату для користувача.

## Види export
- HTML file;
- ZIP package;
- markdown docs;
- recovery package.

## Умови
- QA пройдений;
- структура валідна;
- назва файлу правильна;
- користувач знає куди класти.

## Правило
Export без пояснення “куди класти” не завершений.
