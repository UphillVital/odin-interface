Режим: СОН

Завдання:
Впровадити HEADER_LOCK_v1.

Критична причина:
У попередніх версіях Lesson Engine шапка була згенерована приблизно, а не взята з еталонного шаблону. Це помилка.

Правило:
НЕ вигадувати шапку.
НЕ реконструювати шапку.
НЕ покращувати шапку без дозволу.

Потрібно:
1. Взяти правильний еталонний HTML-файл уроку/шаблону.
2. Витягнути з нього:
   - header HTML
   - header CSS
   - header JS
   - anchor/menu logic
3. Створити HEADER_LOCK_v1.
4. У Lesson Engine вставляти header тільки 1:1.
5. QA має перевіряти HEADER_LOCK fingerprint.

Поки еталонного файлу немає:
- не робити нову шапку;
- не вигадувати;
- працювати тільки з механізмом lock/extract/inject.
